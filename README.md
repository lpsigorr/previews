# previews

Private preview pages for prospects. One folder per prospect: `<slug>-<code>/`.

- Every page has `noindex`, so search engines leave it out. Pages are still public to anyone with the link.
- Never link this repo or its pages from the portfolio.
- Folders are created by `tools/publish.py` in the Studio vault. Push to publish.
- Remove a prospect's folder once they decline or once their real site is live.
